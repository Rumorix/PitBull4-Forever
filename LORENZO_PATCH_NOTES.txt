Patch 090 - LegacyProfileUpgrade

- Added a new top-level Profile Upgrade page between Edit Mode Backup and Profiles.
- The page scans the currently selected profile for known legacy stock LuaTexts that need Midnight 12.1 compatibility updates.
- Added exact migration support for the five stock Name LuaText presets shipped by older PitBull releases; their saved source code is upgraded to the current secret-safe SetFormattedText format without changing layout placement, font, size or other visual settings.
- The same one-click upgrade also persists the maintained Class, Health-percent and Power legacy normalizations across every layout in the current profile.
- Custom Name LuaTexts are detected and reported but intentionally left unchanged.
- If no full safety snapshot exists, Profile Upgrade creates one automatically before modifying the profile. Existing full safety snapshots are preserved.
- The UI reloads after a successful migration so LuaTexts and frame state are rebuilt from the upgraded profile.
- Retains Patch 089 stable Config Mode preview envelope, Patch 084 Edit Mode frame inspector, Patch 083 backup/restore tooling, and all previous Midnight 12.1 fixes.
